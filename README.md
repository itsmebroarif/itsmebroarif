## 📖 Biography

**Arif Permana Putrasuryana** is a fullstack web developer and UI/UX designer based in **Depok, West Java, Indonesia**, with more than **four years of professional practice** spanning frontend engineering, backend architecture, interface design, and digital training. He began writing HTML and CSS as a self-taught student, formalised that craft through vocational study in **Rekayasa Perangkat Lunak (Software Engineering)**, and completed a two-year web development programme at **freeCodeCamp (San Francisco, USA)** — a path that shaped a working method grounded in clarity, structure, and measurable outcomes.

His practice deliberately unites two disciplines that are often separated: **the functional discipline of software engineering** and **the aesthetic discipline of interface design**. Working across **Vue.js, React, Laravel, Node.js, Go, MySQL**, and **Figma**, he delivers production websites, registration and reporting systems, REST APIs, and internal tools — and has additionally served as a trainer for HTML, CSS, JavaScript, Vue.js, and Laravel cohorts. Beyond engineering he handles visual identity, video editing, and hardware maintenance, giving him end-to-end ownership of the products he ships.

Currently engaged as a **Fullstack Web Engineer** at **Sintesa Persada Teknologi** and **Sadaraga**, he is selectively open to new collaborations, freelance commissions, and full-time opportunities.

## ⚙️ Workflow

Every change that lands on `main` is verified automatically before it reaches visitors.

| Check | Tool | Purpose |
|---|---|---|
| JavaScript syntax | `node --check js/main.js` | Guarantees the interaction engine never breaks silently |
| Required assets | Shell gate | HTML, CSS, JS, media, fonts and documentation must all be present |
| Internal references | Link resolver | Every `href`/`src` in `index.html` must resolve to a real file |

```text
push / pull request
        │
        ▼
┌───────────────────┐   ┌────────────────────┐   ┌──────────────────────┐
│  Syntax check     │──▶│  Assets check      │──▶│  Internal link check │
│  node --check     │   │  media · fonts     │   │  href/src resolution │
└───────────────────┘   └────────────────────┘   └──────────────────────┘
        │                          │                         │
        └──────────────────────────┴─────────────────────────┘
                                   │
                                   ▼
                        ✅ GitHub Pages deploy
```

![Portfolio CI](https://github.com/itsmebroarif/itsmebroarif/actions/workflows/portfolio-ci.yml/badge.svg)

**Conventions:** conventional, descriptive commit messages · relative asset paths (portable to any sub-path or domain) · cache-busted `css`/`js` versions on release · zero build step, zero framework.

## ✦ Featured Project — *Persona 3 Reload Portfolio*

<a href="https://itsmebroarif.github.io/itsmebroarif/">
  <img src="assets/screenshots/main-menu.png" alt="Persona 3 Reload inspired portfolio main menu" width="100%">
</a>

A **menu-driven, single-page portfolio** engineered with plain HTML, CSS and JavaScript — no framework, no build step.

- 🎴 Nine-section slanted main menu — **Project · Store · Mini Games · Education · Organization · Skills · Gear · About · Contact**
- 🎬 Dedicated background video per section with preloading
- 🎵 Original audio design: looping backsound with fade-in, plus menu and navigation SFX
- 🃏 Skewed card-stack sub-pages with auto-scroll and selection tracking
- 🛍️ Store section with a `PRODUCT` menu — 16 illustrated, category-filterable products (ERP, SIMRS, LMS, POS, HRIS, e-commerce, QR menu …) ready to order
- 🕹️ **Mini Games arcade** — four playable **three.js** 3D games inside the page (*Shadow Dodge*, *Evoker Target*, *Block Breaker*, *Ring Rush*) with a live HUD, attract mode, procedural SFX and saved best scores
- ⚔️ Persona-style skill screen — skill groups presented as Personas (Orpheus, Thanatos, Orpheus Telos, Messiah) with element-typed chips and fully readable skill names
- ⌨️ Keyboard-first navigation and routable deep links (`?page=…`, e.g. `?page=minigame&game=ring-rush`)
- 🌐 Cross-browser audio recovery (Chrome, Firefox) with a desktop-first notice for small screens
